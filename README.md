# khairat_biladi

Yogurt Factory Management System

📌 Project Overview

Khairat Biladi is a Java-based console application developed to manage the basic operations of a yogurt factory.

The system provides a simple way to manage yogurt products and track production records. It aims to organize factory operations, reduce manual work, and make product and production information easier to access.

🎯 Project Objectives

- Organize and manage yogurt product information.
- Record production operations.
- Track production quantities and dates.
- Provide a simple and user-friendly management system.
- Apply Object-Oriented Programming (OOP) concepts using Java.

✨ System Features

The system provides the following features:

No.| Feature| Description
1| Add Product| Add a new yogurt product.
2| View Products| Display all available products.
3| Search Product| Find a product using its ID.
4| Record Production| Register a new production operation.
5| View Production| Display recorded production operations.
6| Exit| Close the application.

Main Classes

- Main.java: Provides the main menu and controls the application flow.
- AppData.java: Stores shared product and production data.
- Product.java: Handles product operations, including adding, viewing, and searching for products.
- ProductionRecord.java: Handles production records and displays production information.

⚙️ Requirements

To run this project, you need:

- Java Development Kit (JDK).
- Visual Studio Code or another Java-supported IDE.
- Git (optional, for version control).

▶️ How to Run the Project

Step 1: Clone the Repository

git clone https://github.com/Khalid-Mohammed3/khairat_biladi.git

Step 2: Open the Project Folder

cd khairat_biladi

Step 3: Compile the Java Files

javac src/*.java

Step 4: Run the Application

java -cp src Main

💾 Data Storage

The application currently stores product and production information in memory using Java ArrayLists.

Note: Data is temporary and will be lost when the application is closed. Permanent database storage is not currently implemented.
